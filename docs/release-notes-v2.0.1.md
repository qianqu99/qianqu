## 本次更新

### 新图标

- 应用图标换成项目作者提供的插画。
- 图标做了圆角裁切、暖色描边和柔和阴影，放在浅色主界面、深色播放页和 Windows 任务栏里都不会显得突兀。
- 侧栏、启动页、首页主视觉、拖拽提示和 GitHub Pages 图标同步使用新插画。

### 品牌调整

- 副标题从「星空播放器」改为「播放器」。
- 顶部标题改为 `qianqu 播放器`。
- 首页主视觉从星野换成插画，并调整光环、阴影和强调色。
- README、Pages 主页、社交预览图和截图全部更新为新的插画风格。

### 版本

- Windows 打包版本升级到 **2.0.1**。
- 打包输出统一到 `dist/`，GitHub Actions 也同步使用新路径。

## 功能

本地音乐 / 视频、B 站收藏夹与订阅合集、网易云 / QQ / 酷狗搜索与歌单导入、歌词匹配与校准、视频全屏影院、窗口按钮交互都与 v2.0.0 一致。

## 验证

- Windows 11 x64 打包运行通过。
- 首页、网络音乐、播放页、视频影院截图已更新。
- 网易云搜索、B 站播放、QQ / 酷狗搜索、视频影院和窗口按钮悬停 smoke 检查通过。

## 安装

1. 下载并解压 `qianqu-v2.0.1-win32-x64.zip`。
2. 双击 `qianqu.exe`。
3. 如果 SmartScreen 提示未知发布者，点「更多信息」→「仍要运行」。
