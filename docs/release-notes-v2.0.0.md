# qianqu v2.0.0 · 星空播放器

这是 qianqu 的第一个 GitHub 正式版本，也是一次完整的大改版。

## 下载

| 文件 | 说明 |
| --- | --- |
| `qianqu-v2.0.0-win32-x64.zip` | Windows 10 / 11 x64 绿色版，解压即用 |
| `SHA256.txt` | 压缩包 SHA256 校验 |

## 本次更新

### 星空与更名

- 软件更名为 **qianqu**。
- 应用图标、侧栏标志、启动页、首页主视觉和拖拽提示统一为一片纯星野。
- 没有星座连线，只有星点、星云和少量星芒。
- 旧版 `%APPDATA%\鲸歌 WhaleSong` 的音乐库、歌单、封面和登录会话会自动迁移。

### 网络音乐

- 新增网易云音乐、QQ 音乐、酷狗音乐，默认来源仍是 Bilibili。
- 支持登录各平台官方页面，导入账号歌单或粘贴公开歌单链接。
- 在线曲目支持收藏、加入歌单、最近播放、失败重解析。
- 音质向平台申请当前账号可获得的最高档；无版权、会员或地区限制会明确提示。
- 在线播放地址自动升级 HTTPS，修复代理加载失败。

### 视频影院

- 播放页全屏按钮或双击视频进入影院。
- 视频铺满整个窗口，保持原始比例。
- `Esc` 或右上角圆形按钮退出，只退出影院、不关闭播放页。

### 界面与交互

- 删除右上角搜索框、添加按钮和缩放条。
- 侧栏「添加文件夹」、首页「添加音乐 / 添加文件夹」、拖拽导入保留。
- 右上角窗口按钮的悬停高亮覆盖完整 44×40 按钮格，四角也能触发。

### 歌词与歌单

- 保留 B 站收藏夹 / 订阅合集导入和歌单更新。
- 保留多来源歌词候选、B 站字幕校验、歌词偏移、逐句对齐和 9 种沉浸主题。
- 在线搜索结果保留平台原始时长，列表和歌词校准更准确。

## 验证情况

- Windows 11 x64 打包运行通过。
- 网易云搜索、320K 播放、歌词、200 首歌单导入通过。
- B 站搜索、音频播放通过。
- QQ / 酷狗搜索和时长解析通过。
- 视频影院进入 / 退出、窗口按钮角点悬停通过。
- 登录后的会员音质需要用户自己的账号验证；未登录时搜索正常，无权限播放会明确提示。

## 安装

1. 下载并解压 `qianqu-v2.0.0-win32-x64.zip`。
2. 双击 `qianqu.exe`。
3. 如果 SmartScreen 提示未知发布者，点「更多信息」→「仍要运行」。

## 已知限制

- 仅发布 Windows x64 绿色版。
- 在线平台接口可能随平台更新而变化。
- 自动歌词匹配不保证每一首 100% 对齐，请使用偏移和双击对齐。
- 不提供绕过版权、会员或地区限制的功能。

## 校验

下载后可以用 PowerShell 校验：

```powershell
Get-FileHash .\qianqu-v2.0.0-win32-x64.zip -Algorithm SHA256
```

结果应与 `SHA256.txt` 中的值一致。
