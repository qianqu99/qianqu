# 常见问题

## 安装与启动

### Windows 提示「未知发布者 / SmartScreen」怎么办？

qianqu 是免费绿色版，没有购买代码签名证书。点「更多信息」→「仍要运行」即可。请只从本仓库的 Releases 下载，不要运行来源不明的压缩包。

### 需要安装吗？

不需要。下载 `qianqu-v2.0.0-win32-x64.zip`，解压后双击 `qianqu.exe`。程序不会写入 `Program Files`，删除文件夹即可卸载。

### 为什么启动后没有声音？

先确认：

1. 底部音量不是 0，也没有静音。
2. Windows 输出设备正确。
3. 本地文件能正常播放；如果只有在线歌曲无声，可能是平台没有返回可用播放地址。
4. B 站或在线歌曲刚解析时会有 1~3 秒等待；失败时会弹提示。

## 网络音乐

### 为什么搜索有结果，但播放提示没有权限？

在线音乐受版权、会员、地区和账号状态限制。qianqu 会向平台请求当前账号可获得的最高音质；平台不返回地址时会明确提示，不会绕过限制。

### 登录安全吗？

登录窗口打开的是平台官方页面，qianqu 不接触密码。Cookie 保存在 Electron 的独立会话分区：

```text
%APPDATA%\qianqu\Partitions\music-<provider>-auth
```

退出登录只清理对应平台的 Cookie，不影响浏览器账号。

### 为什么 QQ / 酷狗账号歌单读不到？

账号歌单接口由平台控制，可能随版本、地区或账号状态变化。可以在导入弹窗里粘贴公开歌单链接或 ID。

### 会下载在线音频吗？

不会。在线播放只解析临时地址，通过本地代理交给播放器，不把完整音频写入磁盘。

### 支持哪些音质？

程序会申请当前账号可获得的最高档。实际音质由平台返回决定，可能是 128K、320K、FLAC 或其他档位；没有权限时平台会拒绝。

## 歌词

### 为什么歌词慢半拍 / 快半拍？

翻唱、AI 重编曲、加速 / 减速、剪辑版本的时间轴和原版不同。用播放页的 `−0.5s / +0.5s` 或快捷键微调；也可以双击歌词行，把该句对齐到当前时间。偏移按曲目保存。

### 为什么 B 站字幕没有当歌词？

课程口播、直播复盘、视频讲解的字幕会被时长覆盖、密度和口播词校验拒绝。只有通过校验、并且与云歌词高度重合的字幕才会作为时间轴。

### 为什么有些歌没有歌词？

可能平台没有公开歌词、歌词 ID 不匹配，或者歌曲是纯音乐 / 伴奏。播放页会显示未匹配或纯音乐状态，不会拿别的歌的歌词硬套。

### 怎么换歌词来源？

播放页点「换词」，可以同时搜索网易云和 QQ 的候选，并标记 Live / 伴奏 / Cover / DJ 等版本差异。选中后按曲目保存。

## 视频与窗口

### 为什么视频上下有黑边？

视频影院铺满窗口并保持原始比例，屏幕比例和视频比例不一致时会出现黑边。这样不会拉伸画面。

### 怎么退出视频影院？

按 `Esc`，或点右上角圆形退出按钮。只会退出影院，不会关闭播放页。

### 右上角按钮为什么整块都能点？

最小化 / 最大化 / 关闭的点击和悬停热区都是完整 44×40 按钮格，四角和按钮之间也能触发。

## 数据

### 数据保存在哪里？

```text
%APPDATA%\qianqu\
```

音乐库、歌单、收藏、最近播放、在线曲目、封面、歌词缓存和登录会话都在这里。

### 怎么重置？

退出 qianqu 后删除 `%APPDATA%\qianqu`。这不会删除任何音乐或视频文件。

### 从音乐库移除会删除文件吗？

不会。只移除播放器记录，不修改磁盘文件。

## 开发与打包

### 为什么 `npm install` 很慢？

Electron 二进制下载可能较慢，可以设置镜像：

```bash
export ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
npm install
```

### 打包输出在哪里？

```text
dist-v200/qianqu-win32-x64/
```

双击 `qianqu.exe` 运行。
