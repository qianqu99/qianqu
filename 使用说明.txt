qianqu v2.0.0
====================

启动：双击「qianqu.exe」。

第一次使用：
1. 点击侧栏左下角「添加文件夹」，或首页的「添加音乐 / 添加文件夹」；也可以把音乐、视频直接拖进窗口。
2. 扫描完成后，音乐会出现在「音乐库」，视频在「视频」。
3. 点击封面或播放按钮开始播放；点底部封面进入大播放页。
4. 播放器旁边的爱心可以收藏；右键歌曲可以加入歌单、下一首播放、在文件夹中显示。

这一版的变化：
- 软件名改为 qianqu。旧版音乐库、歌单、封面和登录状态会自动迁移。
- 右上角的搜索框、添加按钮和缩放条已删除。搜索仍可用 Ctrl+K，添加仍可用侧栏和首页按钮。
- Apple 试听已删除。
- 网络音乐有四个来源：Bilibili、网易云、QQ 音乐、酷狗，默认 Bilibili。
- 登录后可以导入账号歌单；也可以粘贴公开歌单链接。音质以账号实际能拿到的最高档为准，不绕过会员、版权或地区限制。

视频全屏：
- 播放视频时，点播放页右上角的全屏按钮，或双击视频，进入全屏影院。
- 视频会铺满整个窗口，保留画面比例，多余区域为黑色。
- 按 Esc，或点右上角的圆形退出按钮，回到普通播放页。

B 站歌单：
- 网络音乐 → Bilibili →「收藏夹/合集」，登录 B 站后可以导入收藏夹和订阅合集。
- 导入后的歌单可以点「更新 B 站歌单」，同步新增和删除的视频。
- 只保存标题、封面、BVID / CID 等信息，不下载视频文件。

歌词：
- 本地歌曲读取同目录同名 .lrc，也支持内嵌歌词。
- B 站和在线歌曲会匹配云歌词；字幕需要和歌词高度重合才会采用。
- 歌词对不上时，用播放页的 −0.5s / +0.5s，或快捷键 [ / ]、{ / } 微调，\ 归零。
- 双击任意一句歌词，可以把这一句对齐到当前播放时间，偏移按曲目保存。
- 点「换词」可以搜索网易云和 QQ 的歌词候选。

快捷键：
Space 播放 / 暂停；Ctrl+O 添加文件；Ctrl+Shift+O 添加文件夹；
←/→ 快退 / 快进 5 秒；↑/↓ 音量；M 静音；F 收藏；Q 队列；N/P 下一首 / 上一首；
L 沉浸歌词；T 切换歌词主题；F11 窗口全屏；Esc 退出视频影院或关闭弹层。

数据位置：
%APPDATA%\qianqu\
音乐库记录、歌单、B 站收藏、在线曲目、封面和歌词缓存都在这里，只记录路径和曲目信息，不复制、不修改、不删除你的音乐文件。
各平台登录 Cookie 保存在 Partitions 下的独立会话目录；退出登录只清除对应平台的 Cookie。

如果 Windows 首次运行提示「未知发布者 / SmartScreen」，点「更多信息」→「仍要运行」即可。
